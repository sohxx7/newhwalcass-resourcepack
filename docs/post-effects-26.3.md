# 26.3 포스트이펙트 적용

기존 효과 14종은 서버의 실제 스킬에 연결되어 있다. 기존 정적 카메라 오버레이 11종은 제거했다.
별도 신규 효과 `hwalcass:fire_border`는 수동 테스트용이다. [불꽃 테두리 안내](fire-border-post-effect.md)를 참고한다.

| 효과 | 기존 스킬 상태 / 대상 |
| --- | --- |
| superstar | Class122 궁 지속 시간, 기존 다리 슬롯 장비 조건 |
| hack | Class106에 피격된 플레이어, deadlock_p -180~-101 |
| electro / electro_pool | Class30 궁, 기존 적 적중 조건과 스킨 구분 |
| jett | Class4 대시 준비 지속 시간 |
| jinx / jinx_sg | Class66 패시브 지속 시간과 스킨 구분 |
| kasimo / kasimo2 | Class52 환수 상태와 스킨 구분 |
| shinobu / shinobu2 | Class109 궁, HP 12 이상 / 1~11 |
| predator_flip / predator_kimchi | Class88 히든 중 전원, 일반은 반전 / 김치는 반전 없이 어두운 두 색 |
| raingirl_film | Class153 히든이 남아 있는 동안 전원, 흑백·약한 노이즈·비 |

11개 장비형 효과는 Game 팩의 `hwalpostfx` 함수가 매 틱 스킬 상태와 장착 위치를 확인한다.
원래 아이템 종류·장착 슬롯·커스텀 태그·스킬 조건을 보존하고 `camera_overlay`만 제거했다.
`HwalPostFx` 커스텀 데이터로 구분하며 실제 add/remove 명령은 상태가 바뀔 때만 실행한다.
효과 종료, 장비 제거, 클래스 변경, 관전, 사망 상태에서 해당 효과만 지운다. 해킹은
피격자에게 적용되므로 피격자의 클래스와 무관하다. 서로 다른 슬롯의 효과와 다른
포스트이펙트는 함께 유지된다. 중도 접속·리로드는 현재 장비와 스킬 상태에 맞춰 재동기화한다.
이미 착용한 구 오버레이도 접속/데이터팩 로드 시 아이템 수정자로 전환하며 기존 커스텀 데이터를 보존한다.

Class109의 HP 선택자는 아이템 검사보다 먼저 적용한다. 잘못된 HP 분기에서 대상이
없다는 이유로 반대쪽 아이템까지 지급되는 기존 조건을 수정했다.

포식자·레인걸은 기존 전역 히든 생명주기로 관리한다. 일반 장비형 효과의 정리는 이 세 효과를 건드리지 않는다.
이번에 제작하지 않은 killua 등 다른 오버레이는 대상에 포함하지 않는다.

## 적용

26.3 서버 코드와 같은 릴리스의 new-26.3.zip을 함께 사용한다. 기본·저사양·일반 BGM은 기존 26.3 배포본을 유지한다.
서버 재시작 시 적용된다. 실행 중에는 `/dpreload Game`, 변경된 Class4/30/52/66/88/106/109/122 팩,
`/sk reload posteffects`, `/sk reload class/88`, `/sk reload class/153`을 반영하고 `/build` → `/r`로 리팩을 갱신한다.

## 검증

분리된 실제 26.3 서버에서 11개 실제 스킬 시작/해제, 시노부 체력 전환, 클래스 변경,
관전/사망/장비 제거/재동기화 33건을 검증했다. 다른 효과 `minecraft:invert` 보존도 검사했다.
기존 장비 업그레이드(커스텀 데이터 보존/정적 오버레이 제거) 및 머리/다리 효과 동시 적용·독립 해제도 통과했다.
14개 효과 모두 실제 26.3 리소스 로더/코덱/게임 셰이더 컴파일러 검증을 통과했다.
GIF는 오프스크린 GPU 미리보기이며 실제 게임 클라이언트의 화면은 조작하거나 확인하지 않았다.
