# 포식자 5킬 화면 반전 (26.3)

- 효과 ID: `hwalcass:predator_flip`. 화면의 두 축을 뒤집어 180도 회전한다. 색상 반전이 아니다.
- 기본 전체 화면 vertex shader와 swap → main 2-pass 구조를 사용한다. 별도 텍스처는 없다.
- Class88 기존 히든 연출의 두 번째 대사부터 90틱(4.5초) 동안 관전자를 포함한 접속 중인 전원에게 적용한다.
- 김치포식자(`wpskin88`)는 `hwalcass:predator_kimchi`를 사용한다. 화면 방향은 그대로 유지하며 반전하지 않는다. 월드의 명암을 기준으로 어두운 영역은 짙은 적갈색 `#782c30`, 밝은 영역은 차분한 초록 `#356943`으로 나눈다. 기존 순수 빨강/초록보다 밝기와 채도를 낮췄다. 중간색·그라데이션·추가 텍스처는 없다. 명암 경계는 RGB 휘도 0.45이다.
- 히든을 시작한 시전자의 스킨을 `class88:cinematic` storage에 저장한다. 관람자의 스킨과 무관하며, 도중 접속자도 같은 효과를 받는다. 종료·라운드 변경·시전자 소실·사망·스크립트 리로드 때 두 변형을 함께 정리한다.
- 서버는 관전 전환 대신 `class/88.sk`에서 이동 좌표를 고정하며 시선 각도는 유지한다. 서버가 수행하는 정상 텔레포트는 허용한다.
- 종료 시 이 효과만 제거하므로 다른 post effect는 유지된다. 기존 대사와 BGM 선택은 그대로다.

수동 확인: `/posteffect add @s hwalcass:predator_flip`, 해제: `/posteffect remove @s hwalcass:predator_flip`.
김치 수동 확인: `/posteffect add @s hwalcass:predator_kimchi`, 해제: `/posteffect remove @s hwalcass:predator_kimchi`. 두 변형을 동시에 추가하지 않는다.
수동 명령은 화면 효과만 검사하며 이동 잠금은 Class88 연출에서 실행한다.

서버 변경과 리팩을 함께 반영해야 한다. 서버가 켜져 있으면 `/sk reload class/88` 및 `/dpreload Class88`, 리팩은 기존 `/build` → `/r` 흐름을 사용한다. 서버 재시작 시에도 자동 로드된다.

검증: 분리된 실제 26.3 서버에서 19개 동작 검사를 통과했다. 이동/점프 잠금, 시선 유지, 관전자 포함, 90틱 후 해제, 게임 모드 보존, 라운드·시전자 소실·사망·스크립트 리로드 정리, 다른 포식자의 선택 시 타이머 보존을 확인했다. 다른 post effect가 남는 것도 명령 결과로 확인했다. OpenGL GPU 네 모서리 픽셀 회전 및 ShaderC Vulkan SPIR-V 컴파일 통과. 실제 Minecraft 클라이언트에서의 최종 화면 감상은 아직 하지 않았다.
