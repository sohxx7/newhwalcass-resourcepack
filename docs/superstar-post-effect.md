# Superstar 파형 — 고정 격자 (26.3)

효과 ID: `hwalcass:superstar`.

원본 위아래 각 30개 막대의 위치와 기준 높이, 청록→보라/분홍 색감을 유지한다.
막대는 PNG 샘플링 대신 셰이더에서 그라데이션 사각형으로 그린다.

렌더 순서:

1. 원본 높이를 기준으로 각 사각형의 높이와 그라데이션을 움직인다. 변화 폭은
   800×450 기준 최대 ±15픽셀이며 효과 영역은 각 가장자리에서 약 103픽셀이다.
2. 최종 합성 직전에 화면 좌표의 고정 격자 마스크로 일정 간격을 지운다.
   가로 줄은 원본에 가까운 위 8.5 / 아래 7.5픽셀 주기, 틈 폭 1.3픽셀이다.
   세로 틈은 원본 막대 사이의 간격이다. 이 값들은 막대 높이·시간과 무관하다.
3. 격자가 잘린 막대를 원래 화면에 합성한다. 중앙과 장면 알파는 보존한다.

이로써 막대가 커지거나 줄어도 격자의 간격과 두께는 늘어나지 않는다.
해상도가 달라도 같은 화면 비율의 격자를 사용하고 경계만 안티앨리어싱한다.
애니메이션은 음원 분석이 아닌 시간 기반이다.

`SuperstarConfig`: `Motion`은 변화량(0~1), `Speed`는 속도다.
`Motion=0`은 원본 기준 높이의 정지 재구성이다. PNG 픽셀 그대로를 표시하지 않는다.

```mcfunction
posteffect add @s hwalcass:superstar
posteffect remove @s hwalcass:superstar
```

Class122의 기존 `camera_overlay`를 제거하고 스킬 시작·종료에 자동 연결했다.
신규팩은 기존 `/build` → `/r` 흐름으로 갱신할 수 있다.

GIF: `C:\단타\0활카스\posteffect\superstar.gif` (이번 버전으로 교체).
실제 셰이더를 합성 배경에 적용한 180프레임/6초 렌더이며 게임 캡처는 아니다.

검증: 실제 26.3 PostChainConfig, 리소스/include 로더, 게임 셰이더 컴파일러 통과.
GPU에서 180프레임 내내 고정 격자 틈이 같은 픽셀 좌표를 비워 두는지 검사했다.
가로·세로 틈, 중앙 시야, 장면 알파 보존과 높이 애니메이션을 확인했다.
4개 해상도 및 장시간 값에서도 렌더링했다. 실제 게임 클라이언트 화면은 아직 확인하지 않았다.
