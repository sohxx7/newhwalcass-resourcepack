# 레인걸 히든: 흑백 영화와 비 (26.3)

효과 ID는 `hwalcass:raingirl_film`이다. 히든 시작부터 종료까지 접속자 전원(관전자 포함)에 적용한다. 흑백 변환, 약한 필름 입자, 가벼운 가장자리 음영, 화면에 흐르는 두 겹의 가느다란 빗줄기를 사용한다. 화면 좌표를 왜곡하지 않는다. 기존 월드 비 파티클과 히든 음악은 유지한다.

`class/153.sk`의 `rgHiddenStart`와 `rgHiddenEnd`가 활성 시전자 전체를 확인해 적용/해제한다. 여러 히든이 겹치면 마지막 시전자가 끝날 때 해제한다. 기존 접속·퇴장·사망·라운드·스크립트 리로드 정리 경로를 그대로 이용한다. 이 효과 ID만 제거하므로 다른 post effect는 유지된다.

셰이더는 26.3 `minecraft:globals.glsl`의 `GameTime`과 `ScreenSize`를 사용한다. 필름 입자는 초당 24회 갱신하며 진폭 계수는 0.028(명암 ±0.014)이다. 빗줄기는 서로 다른 속도로 흐른다. 두 레이어의 밀도는 48/28, 밝기 혼합은 0.18/0.24이며 화면 중앙에서는 비의 강도를 60%로 낮춘다. 최대 혼합도 0.32로 제한해 시야를 가리지 않도록 한다. 별도 텍스처는 필요 없다.

실행 중 서버 반영: `/sk reload class/153`, `/build` → `/r`. 서버 재시작 시 스크립트가 자동 로드된다.
화면만 수동 검사: `/posteffect add @s hwalcass:raingirl_film`; 해제: `/posteffect remove @s hwalcass:raingirl_film`.

검증 결과:

- 실제 분리된 26.3 서버에서 관전자 포함 전원 적용, 적 전멸 시 종료, 중첩 시전자 보존, 재시작, 접속 때 쓰는 동기화 경로, 라운드/사망/게임 단계 변경/스크립트 리로드 시 해제 확인.
- 다른 효과 `minecraft:invert` 보존 및 기존 `minecraft:bgm.class153_2` 재생 확인.
- OpenGL GPU 렌더 3개 시점에서 모든 픽셀 RGB 동일, 알파 보존, 시간에 따른 애니메이션 확인. Minecraft의 실제 Globals 선언을 사용한 Vulkan ShaderC 컴파일 통과.
- 테스트용 합성 장면 렌더를 육안 확인했다. 실제 Minecraft 클라이언트에서의 최종 연출 확인은 아직 하지 않았다.

검증 중 기존 `rgGrow`/`rgFade`의 가변 보간시간 구문 두 곳을 명시적인 timespan 파싱으로 수정했다. 시간 수치는 변경하지 않았다.

2026-10-28: 기존 히든 생명주기 연결을 유지하고 노이즈·비의 밀도와 밝기를 낮췄다. 분리된 26.3 서버에서 전원(관전자 포함) 적용, 두 시전자 중첩, 첫/마지막 시전자 종료, 재시작, 접속 동기화 경로, 라운드 변경, 사망 디스패치, 게임 단계 변경, 스크립트 리로드, 적 전멸의 11개 검사를 통과했다. 각 검사에서 다른 효과 `minecraft:invert` 보존도 확인했다. 실제 26.3 리소스 로더·PostChainConfig·셰이더 컴파일러 검증 통과. 오프스크린 GPU 렌더에서 4개 해상도, 6초 애니메이션, 장시간 타임스탬프의 흑백·알파 보존을 확인했다.
