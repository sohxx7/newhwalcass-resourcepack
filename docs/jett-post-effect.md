# Jett 상승기류 바람 (26.3)

효과 ID: `hwalcass:jett`.

2026-10-30: [발로란트 공식 제트 상승기류 영상](https://playvalorant.com/en-us/agents/jett/)을
참고해 움직임을 다시 만들었다. 원본 PNG의 양옆 배치와 반투명한 흰 바람을 기준으로,
가늘고 긴 바람 결과 굵은 붓 자국 같은 바람 띠를 GLSL로 겹쳐 그린다.
각 바람의 가늘어지는 앞뒤 끝과 굴곡이 함께 위로 이동한다. 좌우는 위상과 결이 다르고,
바람이 화면 밖으로 완전히 나간 다음 다시 들어오므로 화면 안에서 끊겨 나타나지 않는다.
전체 애니메이션은 8초마다 같은 상태로 돌아온다.

후속 조정: 양쪽 각각 7개 바람 묶음을 겹친다. 각 묶음은 넓고 반투명한 바람 면과
굵기가 다른 4개 결로 구성하고, 그 사이로 더 빠른 바람줄기 7개가 별도로 흐른다.
묶음별 속도·진입 시점·굴곡이 다르며 바람이 비는 시간을 줄였다. 이전 버전보다
굵기와 동시에 보이는 바람 면적을 늘려 원본의 여러 겹이 겹치는 느낌을 살렸다.

신규팩의 `/build` → `/r` 이후 수동 확인:

```mcfunction
posteffect add @s hwalcass:jett
posteffect remove @s hwalcass:jett
```

`JettConfig`: Motion=1.0, Speed=1.0. Motion=0이면 원본을 그대로 표시한다.
일반 설정의 바람은 셰이더로 생성한다. 원본 텍스처는 바이트 그대로 보존했다.
효과 ID와 Class4의 기존 적용·해제 조건은 같다. 중앙 화면과 장면 좌표는 고정이다.

GIF: `C:\단타\0활카스\posteffect\jett.gif` (별도 GPU 렌더링, 240프레임/8초/30fps).
실제 26.3 포스트 체인 코덱·텍스처 조회·include 로더·GLSL 컴파일러(두 depth 설정) 검증 통과.
GPU 두 패스 렌더링에서 4개 해상도, 장시간, 밝고 어두운 배경, 중앙·장면 알파 보존을 확인했다.
Motion=0의 원본 비교는 RGB 오차 최대 1, 8초 반복 시작/끝은 오차 0이다.
8개 시점의 연속 프레임 이동량을 비교해 모두 위쪽 이동(800×450에서 프레임당 15~24px)을 확인했다.
40개 시점의 바깥쪽 영역을 비교했을 때 눈에 보이는 바람 면적은 직전 버전의 약 1.56배다.
실제 게임 클라이언트 화면은 아직 확인하지 않았다.
